

# MRAKE - AI-Powered System Control

![Jarvis](https://your-image-url.com/jarvis-banner.png)

## Overview
Inspired by Marvel's legendary AI assistant, Jarvis, this project brings an intelligent, responsive system control assistant to your computer. It is designed to execute customized commands, monitor system activities, and provide full control over your system using a fine-tuned local AI model.

## Features
- 🚀 **AI-Based System Control**: Execute custom commands and automate system tasks using a locally fine-tuned AI model.
- 🎙️ **Voice and Text Commands**: Interact with Jarvis using voice or text input.
- 📊 **System Monitoring**: Track CPU, memory, disk usage, and running processes.
- 🔐 **Secure Authentication**: Enjoy a secure login system backed by MySQL.
- 📩 **Contact Form Integration**: Easily send messages via the integrated contact form.

## Installation
### Prerequisites
- 🐍 Python 3.x
- 📷 OpenCV
- 🔥 PyTorch
- 🗄️ MySQL Server
- 📱 Kotlin (for Android integration)
- 🌐 Node.js (for backend API if required)
- 🤖 Ollama (for AI model deployment)

### Setup
1. **Clone the repository**:
   ```bash
   git clone https://github.com/your-username/ai-system-control.git
   cd ai-system-control
   ```
2. **Install dependencies**:
   ```bash
   pip install -r requirements.txt
   ```
3. **Set up Ollama**:
   - Install Ollama by following the official installation guide: [Ollama Docs](https://ollama.com/download)
   - Download the model from the Hugging Face profile **"krsnastuta1/llama-3.1-iio"** — **"unsloth.Q5_K_M.gguf"**.
   - Start the Ollama service.
   - Create the Ollama model using (Command Prompt):
     ```bash
     ollama create iio -f ./Modelfile
     ```
 4.Donwload and Install - https://www.nirsoft.net/utils/nircmd-x64.zip - For Executing Commands.

5. **Run Jarvis**:
   ```bash
   python MRAKE.py
   ```
6. **For Android integration**, build and install the APK using Android Studio.
